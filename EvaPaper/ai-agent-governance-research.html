THE SYNTHESIS

Three Critical Questions Answered

Q1

Do Skills Affect Behavior?

YES — EMPIRICALLY PROVEN

Eight papers provide a cumulative, multi-method evidence base. The effect is measurable, material, and causally demonstrated — not just anecdotal. Markdown formatting changes behavior by up to 40%. Agents show 50x compliance spikes with AGENTS.md instructions. Markdown Awareness correlates with instruction-following.

Q2

Can We Check Before Runtime?

YES — ZIPPERGEN BREAKTHROUGH

ZipperGen provides formal well-typedness checks, deadlock-free-by-construction guarantees, and syntax-directed projection — all before any agent runs. For single-agent skills, SkillFortify and SkCC provide formal static analysis. The remaining gap is behavioral typing of message content.

Q3

Can We Enforce at Runtime?

YES — WITHOUT LLM-AS-JUDGE

Deterministic runtime enforcement exists at both single-agent (ACP at 739-832ns, ABC/AgentAssert at <10ms) and multi-agent (ZipperGen with structural induction proof) levels. The coordination structure is guaranteed correct regardless of LLM nondeterminism.

THE METHODOLOGY

From Human SOP to Agentic Workflow

The four-step conversion process that bridges human intent and formal verification.

01
STEP 01

Format Standardization

Parameterize SOPs, apply MUST/SHOULD/MAY rules (RFC 2119), structure with Markdown for machine parseability. Transform unstructured prose into schemas agents can systematically interpret.

02
STEP 02

Task Decomposition

Split into independent pipeline steps with explicit inputs, outputs, and success criteria. Connect via structured artifacts (JSON) passed from one agent to another.

03
STEP 03

Bidirectional Development

Deploy, observe failures, refine SOP with new rules, iterate. Real-world failures expose tacit knowledge that was never documented. Each iteration builds robustness through feedback.

04
STEP 04

Integration & Execution

Connect to real tools via MCP. Add human-in-the-loop for high-risk decisions. Enable production-ready automation with human oversight at critical checkpoints.

THE FRONTIER

What Remains Open

The biggest gap is not formal verification — it is the formal specification process that precedes it. ZipperGen assumes you already have a formal global specification. But in practice, you start with a human SOP.

01
Behavioral typing of LLM action content
ZipperGen treats LLM actions as opaque. No paper verifies what LLMs compute inside action blocks.
02
Skill-skill composition within a single agent
No static analysis of how multiple skills loaded by one agent interact.
03
Blame assignment in multi-agent violations
When something goes wrong, who is responsible? ZipperGen provides no mechanism.
04
Automatic rollback
ABC has Recovery contracts for single-agent, but multi-agent rollback is unaddressed.
05
SOP-to-specification extraction
Tools that convert human SOPs into formal global workflows, iteratively refined from runtime failures.
